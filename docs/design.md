# Asset Watch デザインルール

画面を作るとき、モックを作るときはこの文書と次の2ファイルに従う。値と部品の正本はリポジトリだけに置き、ほかの場所（Claude Designなど）へは複製して使う。

- 値（色・書体・余白・角丸）: `src/styles/tokens.css`
- 部品（パネル、横棒、凡例など）: `src/styles/components.css`

## 書かないもの

- 説明文、注記、補足の一文は画面に置かない。数字とラベルだけで読めるようにする。
- 数字だけでは何の値か分からないときに限り、数字の前に短いラベルを付ける（例: `純資産 ¥9,500,000`、`JPY 30.3%`）。

## 用語

| 画面の表記 | 意味 |
|---|---|
| キャッシュポジション | 負債を円現金から控除した純資産に占める現金の比率。投資資産選択時は分子・分母から生活防衛資金も控除 |
| 日本円現金 | 口座残高上の円現金 − 全負債。総資産から円現金以外の資産と負債を引いて自動計算。保存値も負債控除済みなので二重控除しない |
| 純資産 / 投資資産 | すべての構成比に適用する分母。純資産は総資産 − 負債、投資資産は純資産 − 生活防衛資金。負の現金は丸めず金額表示し、分母が0以下なら比率は「—」 |
| キャッシュ（生活防衛） | 円現金のうち生活防衛資金の分 |
| キャッシュ（待機資金） | 円現金のうち生活防衛資金を除いた分 |
| キャッシュ以外 | 現金以外の資産の合計 |
| 金融資産 | 現金を除いた資産。銘柄・集中度の構成比も純資産 / 投資資産を分母にする |
| キャッシュ込み | 現金を含めた全体。構成比の分母 |
| JPY / USD | 通貨。通貨パネルでは現金かどうかを区別しない |

## 色の役割

色は意味ごとにトークンを使い分け、同じグラフの中で1つの色に2つの意味を持たせない。1本の横棒に出す色は6色までにし、それを超える分はまとめる。

| 役割 | トークン | 使う場所 |
|---|---|---|
| 資産クラス | `--class-*`（`--cat-1`〜`--cat-8`、`--cat-other`） | 資産・負債、資産クラス |
| 銘柄 | 上位5件に `--holding-1`〜`--holding-5`、6件目以降は `--holding-rest` | 銘柄の横棒と一覧 |
| 通貨 | `--fx-jpy` `--fx-usd` `--fx-eur` `--fx-other` | 通貨パネルのみ |
| キャッシュ | `--class-cash`。生活防衛資金は `.aw-hatch` を重ねる | キャッシュポジション、銘柄 |
| キャッシュ以外 | `--cat-other` | キャッシュポジション |
| 負債 | `--liability` | 資産・負債 |

- 資産クラスと通貨の色は固定する。金額順に並べ替えても色は変えない。
- 銘柄は評価額の大きい順に上位5件だけ色を当てる。横棒では6件目以降を「残りN銘柄」の1区画にまとめ、一覧では灰色の棒で全件を出す。同じ色の番号は銘柄パネルの中だけの意味で、資産クラスとは関係ない。
- 塗りの上の文字は、どの塗りでも `--on-chart`（ライトは白、ダークは黒）。新しい塗りを足すときは、`--on-chart` とのコントラストが4.5:1以上になる明るさにする。
- ダークはライトと同じ色相のまま明るくする。テーマで色の意味を入れ替えない。
- 斜線（`.aw-hatch`）は横棒の区画では下端の帯だけに引き、文字に重ねない。

## 部品の使い分け

| 見せたいこと | 部品 |
|---|---|
| 内訳の構成（合計が100%） | `.aw-alloc`（100%横棒） |
| 分母の違う100%横棒を並べる | `.aw-alloc-rows` の中に `.aw-alloc` を並べる |
| 項目ごとの大小 | `.aw-bars`（大きい順の横棒一覧） |
| 構成比を2つの分母で並べる | `.aw-bars.aw-bars--dual` |
| 主要な比率 | `.aw-stats` の中に `.aw-stat` |
| 総資産 − 負債 ＝ 純資産 | `.aw-wf` |
| 分母の切り替え | `.aw-seg` |

- `.aw-alloc` の区画には、収まる範囲でできるだけ文字を書く。「名前 構成比／金額」→「名前／構成比」→「名前」→「構成比」→なし の順に減らす。名前が長く収まらない棒（キャッシュポジションなど）は、区画には構成比と金額だけを書き、名前は凡例に出す。
- どの区画も、マウスを載せる・タップする・キーボードで選ぶと、名前・金額・構成比を出す。区画に書けなかった項目もこれで必ず確かめられるようにする。
- 凡例（`.aw-legend`）は、区画に書けなかった項目だけに付ける。すぐ下に同じ色の一覧があるときは凡例を省く。

## ライトとダーク

- 両方を必ず用意する。ダークの値は `tokens.css` のダークの塊に書き、`@media (prefers-color-scheme: dark)` と `:root[data-theme="dark"]` の2か所を同じ値にそろえる。
- 表示はメニューの切り替えボタンで「自動（OSに合わせる）→ライト→ダーク」と選べる。選んだ値は `html` の `data-theme` に入る。
- 画面を確かめるときは、ライトとダークの両方を見る。
